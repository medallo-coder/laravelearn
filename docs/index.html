🕊️ Sistema de Registro de Personas Desaparecidas

📌 Descripción

Este proyecto es una aplicación web en desarrollo cuyo objetivo principal es registrar, organizar y consultar información relacionada con personas desaparecidas, personas localizadas y cuerpos no identificados, con el fin de apoyar los procesos de búsqueda, identificación y memoria.

El sistema busca centralizar información relevante para facilitar el trabajo de organizaciones, colectivos de búsqueda y personas interesadas en la documentación de estos casos.

🎯 Propósito del Software

El propósito de este software es:

  • 📋 Mantener un registro estructurado de personas desaparecidas
  • 🔍 Registrar información cuando una persona aparece con vida
  • ⚰️ Llevar un control de cuerpos encontrados sin identificar
  • 🧾 Documentar características físicas, señas particulares y vestimenta
  • 🏛️ Relacionar casos con organizaciones y zonas de búsqueda
  • 🕯️ Contribuir a la memoria, visibilización y dignidad de las personas desaparecidas
